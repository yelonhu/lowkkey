# Provider marks

Official provider artwork. AI SVGs are copied without path, proportion or color changes. Used only to identify the connection or sign-in provider; marks remain owned by their respective companies.

- ChatGPT: OpenAI black/white monoblossom, from https://cdn.openai.com/brand/OpenAI-Logos-2025.zip (OpenAI-logos(new)/SVGs). Brand guidelines: https://openai.com/brand/.
- Claude: Claude Spark - Clay.svg, from https://anthropic.com/press-kit (Anthropic media resources/Anthropic logos/Claude logos/3 Claude Spark/SVG).

OpenAI uses the supplied white version on dark backgrounds. Claude retains its supplied Clay color in both modes. Assets are served locally.

- Google: current full-color G, copied from https://developers.google.com/static/identity/images/g-logo.png (linked by https://developers.google.com/identity/branding-guidelines). Used for the Google sign-in action; original colors and proportions preserved.
