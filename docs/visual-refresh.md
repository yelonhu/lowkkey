# M1.1 · 清透蓝视觉审阅

日期：2026-09-17。状态：本地自动化验收通过，待用户审阅。本批仅更新 M1.1 外观与文案，等待用户审阅后再继续。

## 打开体验

在 `~/Developer/craft/lowkkey` 执行 `./scripts/run dev`，打开 [本地预览](http://127.0.0.1:5173/)。原有开发数据保留；首次进入可使用“打开本地演示”。

[打开前后截图对比](../.artifacts/visual-refresh/review.html)：可切换首页、称重、明暗及桌面布局。截图来自独立 Chromium 测试，使用虚构数据；新旧截图的测量值可能不同，称重局部图保留原测试的取景方式。

建议依次体验：
1. 首页三舱：确认层次、蓝色称重按钮、等宽读数和简洁标题。
2. 称重：输入、保存、修改、删除、十秒撤销；检查错误、异常确认和真实同步反馈。
3. 切换简中、繁中、英文及系统明暗，观察日期、单位和既有记录保持不变。
4. 输入半个数后进入对话，再返回记录；检查草稿、焦点与返回位置。

## 实际变化

- 微冷白背景、纯白卡片、18px 圆角、细边框和两层淡阴影；按钮与输入为10px圆角。
- 主按钮轻微蓝色渐变；中性次要操作；错误与警告使用独立颜色，同时保留文字说明。
- 标题、品牌与正文采用系统无衬线；读数、数字输入、日期和图表刻度使用系统等宽字体。格式化后的数值只增加展示标记，不解析或改写事实。
- 首页改为“今日状态 / 今日狀態 / Today”；登录、称重、对话和设置的相关标题同步调整。
- 系统深色配套石墨灰表面；约160ms交互反馈；减少动态效果时禁用动画与过渡。
- 更新浏览器主题色、PWA默认浅色启动背景和 SPEC v1.1.2。继续使用原生 CSS，没有增加 Tailwind、字体依赖或字体外部请求。
