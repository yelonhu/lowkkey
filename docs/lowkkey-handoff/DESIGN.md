# lowkkey：日用 AI 数据底座与私人展厅

对话、随手记、截图与澄清留在用户熟悉的 AI 中。应用保存真实记录并展示成果，外部 AI 经明确授权直接写入。

## 产品边界

三张业务表、四个 MCP 工具、三屏成果。没有现场训练模式、计时器、快捷记组、捕获栏、离线写入队列、审批弹窗、提议收件箱或自动加重与饮食建议。

登录、账户隔离、导出与 AI 授权属于基础能力，收于「设置」面板，不增加业务导航。入口只使用文字，不加箭头；面板按 AI 连接、数据、登录分组。

## 视觉与信息架构

沿用 frontend/lowkkey-frontend.html 的纸白背景 #F1F1EF、墨色 #141415、灰色细线、蓝色数值 #2C4A66、宋体标题和 Geist 数字。原画板仅作设计参考，不加载其中示例事实。

- 页面以内容为主：简洁单行标题和真实记录数量，去除抒情开场及装饰性英文编号。用字重、对齐、留白和少量蓝色建立层级，不使用厚重阴影或原生 iOS 控件拟态。
- 下次练什么：每个有动作的训练日一张轻边界纸面卡；训练日、动作与目标重量突出，组次、要点及教练备注次之。
- 训练展厅：卧推、深蹲、推肩、引体四幅小图，桌面四列、窄屏两列；历史原话为阅读主体，桌面日期列与内容分开，手机按顺序阅读。最佳组用颜色和字重强调。
- 体重：7 自然日均线为主图，均值为主数字；测量日期、lb、样本数与最近测量作为辅助信息。显式设置增重目标后展示参考带。
- SVG 按容器实际宽度排版，标签保持可读字号；日期跨年时包含年份。空库每屏只提供一段说明，不展示重复空图表或虚构数字。

直接使用 React 和 SVG。空数据只展示空状态；长原话保留换行且安全转义；支持 320px 手机、平板和桌面，尊重减少动态效果设置。字体未加载时使用宋体与系统无衬线回退。设置打开时锁定背景滚动和焦点，关闭后恢复入口焦点。导航使用 #Plan / #Gallery / #Weight，旧 Body 映射体重、Progress / Ledger 映射展厅，其他旧入口回到计划。

## 数据与计算约束

训练按日期保存完整原话及有序组，体重按日期保存磅数，计划按训练日保存。覆盖语义和日期由外部对话明确；相同内容重试不新增事实。

身体备注与增重目标通过计划元数据保存独立更新序号；字段省略不会改变已有全局上下文，显式 null 是清空标记。

e1RM、有效负荷、7 日均值和目标带由共享领域包现算。模型、数据库和页面均不另存或猜测这些派生值。具体公式见 INTERFACE.md。

页面启动及重新获得焦点、恢复可见或网络连接时读取事实。没有 SSE、后台业务写入或自动轮询；获取失败保留当前显示并提示重试。退出登录会清除内存事实，过期响应不会重新填入。
