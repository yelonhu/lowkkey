# lowkkey v5 实现约定

用户确认的 v5 HTML 是唯一视觉基准。完整原稿含私人记录，不提交到仓库。`src/app/style.css` 前段为原稿 CSS 原样提取，追加部分仅负责运行时适配与画卷外的设置面板。字体通过 Google Fonts 加载 Inter 400/500/600 与 Noto Serif SC 400/500/600，字体栈、三套深浅 token、SVG 图形尺寸和原文沿用原稿。

## 四页

- next：Chicago 今天起七天内的下一安排，当天练过则跳过。动作、组次、可选、上次紧凑组、节奏图、配片、备注及 later 展开。
- recap：最近周信（缺本周时回退并标周），五类 picks，四线相对变化及可点选焦点，四项读数、heaviest 和 contact sheet。
- body：真实最近称重、至少四次的七日均值、至少八次的十四日回归速度、目标状态，日测点、历史目标线与未来四周参考带，周均值表。
- log：按周倒序，Claude 批注与用户「原话」分开。动作行展开逐组热身、降重、递减、借力与未完成。

品牌按钮外观不变，点击进入设置（AI 授权、导出、刷新、退出）。不增加箭头、设置文字或同步页脚。顶部不显示主题选择；AI 主题跨周延续，未来周到期生效，无选择时水墨。旧 Plan/Gallery/Weight 链接映射至 next/log/body 并保留定位。

## 运行时边界

没有计划、训练或称重时使用说明规定的单句空状态，不造数据。不足样本隐藏均值/速度或目标状态。没有目标不画带；没有可用体重不画辅助比例，不计算相关 e1RM。只有一点时画点并标「第一次」。删除事实后失效引用不渲染。next 建议按目标日匹配；body 批注七天后失效，显式清空不复活旧建议。

页面进入、获得焦点及从其他应用返回时刷新。日期切换以 America/Chicago 为准。图按实际容器宽度绘制，取消原型 300px 最小宽；保留圆点外观并扩展触摸区。导航吸顶、安全区、键盘读数、焦点管理、减少动态效果和 320px 溢出适配属于必要运行改动。

## 验收

Chromium / WebKit 检查四页、320/390/1280px、三套深浅主题、长文字、无字体服务、账户设置与跨应用刷新。私密数据验收固定 2026-10-08，截图仅存在 `.artifacts/private-reference`。公网按真实日期运行。浏览器自动化不是 iPhone Safari 真机验收；真人设备和 Claude 官方客户端工具刷新须单独记录。

## 安静的连续交互

导航使用一条 240ms 滑动下划线；各页保持挂载和阅读位置，notes 不参与正文位移动画。展开 240ms，可在当前高度反向；设置进入 280ms / 退出 180ms，完成后恢复焦点。主题 400ms 颜色过渡，局部内容更新 180ms 淡换。图表读数即时响应；真实新 PR 只在既有主项位置短暂强调，历史基线与重复刷新不重播。减少动态效果时全部即时完成。

随手记任何输入焦点均无框，键盘 Tab 在日期处给提示，保存小字预留空间。AI 连接按显示名称折叠各次授权并保留真实 ID；批量断开逐项处理并报告部分失败。设置移除主屏幕安装提示。

## 手机横滑与朋友 beta

触摸在展示正文或留白起手可左右切换五页，不循环。10px 后按横纵 1.3 倍锁定方向；超过 25% 宽度，或至少 40px 且速度 0.5px/ms 时切换，否则回位。两侧 24px 留给系统返回。图表、笔记正文、冲突原文、操作控件及横向滚动区域不抢手势；输入聚焦期间停用。垂直滚动、缩放与文字编辑保留原生行为。

真实页面节点在临时裁剪视口内跟手，保持编辑器、展开和滚动状态；下划线同步插值。收尾 180–280ms，可从当前位置反向；只有完成才写入 hash，取消不增加历史。减少动态效果时即时切换。展示文字默认不可选，笔记、冲突原文、连接地址、错误详情和隐私正文可正常选择复制。

朋友 beta 真机验收尚需单独记录：iPhone Safari 横滑、边缘返回、键盘、图表、长笔记；首次使用者独立完成 Google 登录 → 隐私确认 → 随手记 → Claude 读取 → 独立授权后按要求追加 → 网页查看。自动化不代替这些验收；公开推广前另核对告警、容量、防滥用及备份恢复。此次先本地交付，不自动发布或联系朋友。

## 状态舱

网页不只是展示，而是一个安静的在场。主题 token 之外新增 `--sky` 与 `--depth`：`.sky` 在 `.showroom-content` 顶部铺一层主题色的径向天光（ink 几乎不可见，gold 暖，pearl 冷），主题变化时以 key 重挂载并 1.2s 淡入；卡片在浅色下有一层极轻的投影，深色下无。品牌后的句点是心跳：3.8s 呼吸，`html[data-syncing]` 时 0.9s；品牌行右侧以 `.mood` 显示本周主题名与 AI 给的理由。

AI 的每段文字（`.cl`、周信正文）统一以一枚 5–6px 渐变墨点开头，取代原先的竖线；用户原话仍用「」。next 页顶部 `.status` 一行：周几与日期、week N（自第一次训练起）、本周完成/计划、七天内最新体重，数据来自 `weekStatus`。空状态改为有声音的一句话，并在没有计划时给出 `#start` 入口。

动效：首次到达每页时前七个顶层块依次浮现（380ms，间隔 48ms），再次进入保持 240ms 淡入；体重大数字 560ms 落定；按压由 `press-feedback` 统一管理 `data-pressed`，行类控件用水洗底，块类控件缩放 .975，移动超过 8px 即取消；在最顶部继续下拉时 `#pull` 墨点随手指浮现，超过 72px 松手触发 `refresh`，完成后「已同步」。手机宽度下设置面板为底部纸，带拖拽把手，向下拖超过 80px 关闭。减少动态效果时全部即时完成。
