## 环境实现依据

核对已安装 Wrangler 源码：macOS 的 `xdgConfig()` 接受 `XDG_CONFIG_HOME`，`getGlobalConfigPath()` 会优先检查旧 `~/.wrangler`，因此额外禁止该旧目录的读取。`WRANGLER_LOG_PATH` 指向项目日志；遥测与错误上报关闭。

核对已安装 Miniflare 源码：`CLOUDFLARE_CF_FETCH_ENABLED=false` 可禁用其默认外网 Request.cf 探测。关闭自动 dotenv 注入和 process.env 注入，Vite 的 envDir 也与根 `.env` 分离。配置只通过白名单显式传递。

Playwright 浏览器下载到 `.toolchain/browsers`，profile 位于 `.local/test-browser`；构建、报告及截图均在 `.artifacts`。

核对锁定 Vitest 5.0.1 源码后发现：即使关闭 API/UI，它也无条件尝试写入 `~/Library/Application Support/vitest/.vitest-secret-token`；XDG 和 Vite cacheDir 都不能重定向此路径。初次审计中此 mkdir 被内核以 EPERM 拒绝，未发生目录外写入。依据 §17.1 的受审适配路径，`scripts/adapt-vitest.mjs` 仅将 token 解析替换为每次进程随机生成的内存 token；API/UI 仍关闭，不降低网络服务认证要求，也不重定义 HOME。适配检查版本及原始源码 SHA-256，重复执行不改变结果，依赖变化则中止。原始 chunk SHA-256：`26c9c3d31efea8bb6e5f6f495db89968ba820a26c0676341f3682ec5377d584d`。

Node 固定包与 checksum 来源：[官方发布目录](https://nodejs.org/dist/v24.21.0/)、[官方 SHASUMS256.txt](https://nodejs.org/dist/v24.21.0/SHASUMS256.txt)。适用环境为本次验证的 macOS arm64；不能外推为其他操作系统已通过。

## 契约决定

- §7 重量语义统一 `unspecified`；其他领域的 `unknown` 不变。
- 非负计量进入规范缩放单位时四舍五入一次；预算向上取微美元；原始十进制字符串保留。
- Access 成员 `verified_subject` 保存经验证 `[issuer, subject]` 的 JSON 字符串，防止跨 issuer 混淆；不合并 Gmail 点号/加号。
- 开发身份 fixture 仅在测试路径可用，发布构建不引用；当前 Worker 仅有无敏感信息的 health 与结构化 404/503。
- SQLite DO 仅是存储验证探针，没有 BudgetLedger 实现，不能用于费用决策。
