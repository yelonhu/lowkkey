# M1 训练修订 — 填写即记录

本批是 M1.4 的交互修订，同时更新三舱首页。保留 RPE、取消完成勾选；饮食能力不扩展，整个 M1 尚未验收。

## 五分钟试用

使用 `./scripts/run dev`，打开 [本地预览](http://127.0.0.1:5173/today)。沿用虚构本地身份与已有数据，无需云端凭据。

1. 从训练卡开始空白训练；若已有进行中的训练，先继续或结束它。选择“杠铃平板卧推”，无需填写器械问卷。
2. 查看“总重 · 单位”标签，需要 lb 时在配置面板选择。填写 `110` 和 `10`，在同一行移到 RPE 时不会保存；点“加一组”后保存。新行只沿用重量，次数与 RPE 留空。
3. 第二行只填重量，打开对话再返回或刷新，半填内容仍在；填好次数并离行，观察已记录组数。
4. 直接修改已有行的次数，离行自动保存。点组号打开详情，查看组类型、备注或明确删除；清空次数不会删除旧记录。
5. 点“结束训练”，最后一行的有效输入会先保存；半填内容可保留草稿后结束。回首页切换语言，数字事实保持不变。

断网测试仅针对已经打开的页面：本机暂存后重连入账。完整离线重开、实机触控与手机键盘仍属于后续共同验收。

## 工程与契约

- 保持既有 set.create/update/delete、训练根版本、幂等回执及统一账本。保存协调层串联离焦与导航；后台切换只存草稿。
- 每行使用稳定 ID、独立原始草稿。旧版单行草稿保留原键和版本绑定恢复；命令入队原子消费对应的草稿版本。保存等待期间继续编辑，新输入不会被旧提交删除。
- 已结束训练收起未触碰的新空行，保留已记录组及明确保留的半填草稿。
- 历史仅作参考；新行、半填内容和未知 RPE／组类型不生成完成事实。待同步行仅用于本机展示，服务端合计仍依据已入账事实。
- 追加 `0008` 迁移，仅增加配置来源 JSON 列；Drizzle schema、快照及 journal 同步。配置及动作快照记录默认版本和本人修改，旧值保持未知。
- 首次标准杠铃建议 20 kg 或 45 lb，后续切换单位保留实际杆重。单侧不乘二；自定义动作不按名称猜含义。器械关键变更生成新 setup，保留旧组快照；未记录且无半填内容的空动作可以被新配置替换。
- JetBrains Mono 2.304 的 WOFF2、OFL 许可及下载来源校验在 `public/fonts/`；应用无字体 CDN 请求。
- 卡片 24px 圆角、无描边、柔和阴影；首页整卡为语义化链接，无嵌套按钮。数字输入、行号和指标实际使用本地等宽字体。
