# iPhone 外壳、自由训练与器械配置验收

## 交付内容

- 外壳只在一处固定定位，手机画板不整体缩放；安全区不参加切页和抽屉动画。
- 主屏幕元数据增加 capable / black-translucent。它是否能解决当前 iOS 的系统状态栏色块，**尚待真机验证**，不能从桌面 WebKit 推断。
- 重量、单位、次数居中对齐；次数支持直接输入；RIR 有选中反馈，再点可取消。编辑中的值和推荐依据不随 SSE 变化，失败重试保留原操作。
- 首页呈现动作名称，取消 A/B 与周期管理入口。无安排可直接“记录训练” → 选择动作；自由记录不生成计划、目标组数或自动加重建议。
- “杠铃与配片设置”可修改 lb / kg 两套物理器械配置，跟随账户同步。改变记录单位不会更换实际杠铃。默认空杆为 45 lb / 20 kg，用户应按现场器械调整。
- 配片仅表示可用规格，不代表库存数量。自定义配片寻找精确解与较少片数，无法精确配出会明确显示差额；不会改变将要入账的重量。
- 原交接 HTML 未修改，认证仍为 Access，无数据库迁移、无个人数据导入。新增用户专属 `/v1/preferences/equipment`，模型只能读取配置。

## 真机操作清单

设备目标：iPhone 15 Pro，iOS 26.6.2；分别记录主屏幕模式和 Safari 结果。

1. 核对 `/healthz` 的 `version`。从多任务中彻底关闭后冷启动首页，观察系统时间、电量所在区域是否有独立色块；进入训练、回首页、日志，再重复冷启动。不要只测试热切页。
2. 比较已有主屏幕入口和更新后新添加的入口。先保留原入口；新建不要求清除 Safari 网站数据或删除 D1 记录。检查状态栏图标在浅色/黑色背景上是否都清晰。
3. 首页聚焦中文输入，打开/关闭键盘、切其他 App 再回来、旋转设备；内容和草稿应保留。训练中重量、次数、单位和提交按钮均可到达。
4. 没有安排也能“记录训练”，搜索并选择真实动作。录入本组真实重量和次数，点选/取消 RIR。提交按钮写清实际数值，快速连点不能重复入账。不要为了验收向本人账户写虚构记录。
5. 在配片设置中选择现场实际的 lb / kg 杠铃，填写空杆和片重。切换输入单位时数字不变，物理器械配置不变；另一设备读取同一账户后能看到配置。
6. 换动作、继续加组、结束训练、查看本场总结，错误记录从日志撤销。AI 改安排不应改变已开始训练的动作快照。

记录每项“通过/失败/未测”，附模式、系统版本、提交 SHA 和录屏。**目前所有真机项均未测。**

## 顶部问题的诊断数据

如仍有顶部色块，用 Safari 打开 `/?viewport=1#Main`，需要复现主屏幕行为时把这个地址另加到主屏幕。通过 Mac Safari 的开发菜单连接 iPhone 网页，在控制台执行：

```js
JSON.parse(document.documentElement.dataset.viewport)
```

只包含屏幕/视口/外壳尺寸、显示模式、安全区 padding 和主题，不含账户数据。分别在冷启动首页、训练页、打开键盘时复制结果，并附同一时刻截图。诊断只在 URL 含 `viewport` 时启用。

若网页外壳已经覆盖浏览器提供的整个视口，而色块仍在该区域之外，应记录为系统区域限制，不能通过硬编码负偏移冒充修复。参考 [WebKit 301994](https://bugs.webkit.org/show_bug.cgi?id=301994)。
